# 51 - CI

Dokumen ini menjelaskan workflow CI yang disiapkan.

---

## 1. Status

Workflow ada di `.github/workflows/ci.yml`.

Workflow belum dijalankan di GitHub Actions karena lingkungan saat ini tidak
memiliki akses ke runner GitHub.

---

## 2. Matriks

Sistem operasi:

- `ubuntu-latest`.
- `macos-latest`.
- `windows-latest`.

Setiap job menjalankan:

1. Checkout repository.
2. Pasang komponen `rustfmt` dan `clippy`.
3. `cargo fmt --all -- --check`.
4. `cargo clippy --workspace --all-targets -- -D warnings`.
5. `cargo test --workspace`.
6. `cargo build --workspace --release`.

---

## 3. Dependensi CI

- `actions/checkout@v4` untuk checkout.
- Rust dan Cargo dari image runner.
- Tidak ada crate eksternal.

---

## 4. Verifikasi Lokal

Perintah yang sama dapat dijalankan lokal:

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo build --workspace --release
```

Semua perintah tersebut sudah lulus di Linux sebelum workflow dibuat.

---

## 5. Batas

- Belum ada bukti eksekusi di GitHub Actions.
- Belum ada caching build.
- Belum ada code coverage.
- Belum ada scheduled run.
- Belum ada artefak release.
