# 29 - Analisis AC

Dokumen ini menjelaskan analisis AC small-signal linear.

---

## 1. Status

P10-01 sampai P10-03 diimplementasikan:

- AC small-signal pada satu frekuensi.
- Sweep frekuensi logaritmik.
- Output magnitude dan phase.

Cakupan saat ini hanya device linear:

- Resistor.
- Capacitor.
- Inductor.
- Voltage source.
- Current source.

Device nonlinier seperti diode dan MOSFET ditolak dengan
`SimError::UnsupportedDevice`.

---

## 2. Complex MNA

- `Complex64` menyimpan komponen real dan imajiner.
- `ComplexMatrix` adalah matriks dense dengan LU dan partial pivoting.
- Struktur indeks sama dengan MNA DC:
  - Node non-ground menempati `0..node_count`.
  - Branch menempati `node_count..node_count + branch_count`.
- Ground tidak memiliki baris.

---

## 3. Stamp Device

| Device | Stamp |
|---|---|
| Resistor | `Y = 1 / R` |
| Capacitor | `Y = j * 2 * pi * f * C` |
| Inductor | Branch dengan `Z = j * 2 * pi * f * L` |
| Voltage source | Branch dengan RHS tegangan AC |
| Current source | RHS arus AC |

Magnitude sumber diambil dari parameter `ac` jika ada. Jika tidak ada:

- Voltage source memakai parameter `voltage`.
- Current source memakai parameter `current`.

Phase memakai parameter `ac_phase` dalam derajat.

---

## 4. API

```rust
pub fn ac_analysis(
    circuit: &Circuit,
    frequency: f64,
) -> Result<AcSolution, SimError>;

pub fn ac_sweep(
    circuit: &Circuit,
    start: f64,
    stop: f64,
    points: usize,
) -> Result<Vec<AcSolution>, SimError>;
```

`AcSolution` menyediakan:

- `frequency()`.
- `node_voltage(node)`.
- `magnitude(node)`.
- `phase_degrees(node)`.
- `branch_current(device)`.

Validasi:

- Frekuensi harus finite dan lebih besar dari nol.
- `stop` tidak boleh lebih kecil dari `start`.
- Sweep membutuhkan minimal dua titik.

## 5. Test

- RC low-pass pada cutoff: magnitude `0.7071`, phase `-45 deg`.
- RL low-pass pada cutoff: magnitude `0.7071`, phase `+45 deg`.
- Current source memakai parameter `current`: `1 mA * 1 kOhm = 1 V`.
- Phase sumber `90 deg` menggeser respons RC menjadi `+45 deg`.
- Sweep mengembalikan jumlah titik yang diminta.
- Frekuensi tidak valid ditolak.
- Device nonlinier ditolak.
