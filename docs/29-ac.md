# 29 - Analisis AC

Dokumen ini menjelaskan analisis AC small-signal dengan linearisasi DC.

---

## 1. Status

P10-01 sampai P10-03 dan P12-18 sampai P12-26 diimplementasikan:

- AC pada satu frekuensi.
- Sweep frekuensi logaritmik.
- Output magnitude dan phase.
- Linearisasi device nonlinier pada DC operating point.

---

## 2. Metode

Alur `ac_analysis`:

1. Hitung DC operating point.
2. Bangun MNA real dari Jacobian device pada titik operasi.
3. Salin matriks real ke matriks kompleks.
4. Tambahkan stamp reaktif capacitor dan inductor.
5. Susun RHS sumber AC.
6. Selesaikan sistem kompleks.

Dengan cara ini, diode, MOSFET, BJT, dan JFET menyumbang `gm`, `gds`,
`gmb`, dan konduktansi small-signal lain melalui Jacobian DC.

---

## 3. Device yang Didukung

- Resistor.
- Capacitor.
- Inductor.
- Voltage source.
- Current source.
- Diode.
- MOSFET N dan P.
- BJT NPN dan PNP.
- JFET N dan P.

Ditolak:

- Pulse voltage source.
- Transmission line.
- VCVS, VCCS, CCVS, CCCS.
- Voltage-controlled switch.

---

## 4. API

```rust
pub fn ac_analysis(
    circuit: &Circuit,
    frequency: f64,
) -> Result<AcSolution, SimError>;

pub fn ac_sweep(
    circuit: &Circuit,
    start: f64,
    stop: f64,
    points: usize,
) -> Result<Vec<AcSolution>, SimError>;
```

`AcSolution` menyediakan:

- `frequency()`.
- `node_voltage(node)`.
- `magnitude(node)`.
- `phase_degrees(node)`.
- `branch_current(device)`.

Magnitude sumber memakai parameter `ac` jika ada, lalu fallback ke
`voltage` atau `current`. Phase memakai `ac_phase` dalam derajat.

---

## 5. Test

- RC low-pass pada cutoff: magnitude `0.7071`, phase `-45 deg`.
- RL low-pass pada cutoff: magnitude `0.7071`, phase `+45 deg`.
- Current source memakai parameter `current`.
- Phase sumber `90 deg` menggeser respons.
- Diode small-signal memakai bias DC.
- Inverter MOSFET memiliki gain.
- Common source JFET memiliki gain.
- Common emitter BJT memiliki gain.
- Switch, transmission line, dan pulse source ditolak.

Total test `sim-analysis`: 96.
Total workspace: 502.

---

## 6. Batas

- Kapasitansi device nonlinier belum masuk ke matriks AC.
  - Meyer capacitance MOSFET belum distamp pada AC.
  - Junction capacitance diode belum distamp pada AC.
  - Kapasitansi BJT dan JFET belum ada.
- Karena itu, respons frekuensi device nonlinier masih kuasi-statis.
- Controlled sources dan switch belum didukung AC.
- Solver AC masih dense.
- Belum ada golden comparison dengan ngspice.
