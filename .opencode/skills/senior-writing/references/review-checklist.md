# Review Checklist

Gunakan checklist ini sebelum mengirim tulisan.

---

## 1. Tujuan

- [ ] Tujuan tulisan jelas dalam 1 sampai 2 kalimat.
- [ ] Pembaca tahu apa yang harus dilakukan setelah membaca.
- [ ] Rekomendasi atau keputusan muncul lebih dulu.
- [ ] Tidak ada latar belakang yang tidak perlu.

---

## 2. Struktur

- [ ] Urutan logis.
- [ ] Setiap bagian punya satu fungsi.
- [ ] Paragraf pendek.
- [ ] Judul dan subjudul informatif.
- [ ] Tidak ada bagian yang mengulang bagian lain.
- [ ] Ada langkah berikutnya.

---

## 3. Isi

- [ ] Setiap klaim penting didukung.
- [ ] Fakta, asumsi, dan opini dipisahkan.
- [ ] Angka punya sumber atau konteks.
- [ ] Tidak ada data yang dikarang.
- [ ] Batasan dijelaskan.
- [ ] Risiko dijelaskan.
- [ ] Ketidakpastian ditandai.
- [ ] Rekomendasi dapat ditindaklanjuti.

---

## 4. Gaya

- [ ] Kalimat aktif.
- [ ] Kalimat tidak terlalu panjang.
- [ ] Tidak ada kata pengisi.
- [ ] Tidak ada hedge berlebihan.
- [ ] Istilah konsisten.
- [ ] Jargon dijelaskan.
- [ ] Tidak ada hype.
- [ ] Tidak ada huruf kapital semua untuk penekanan.
- [ ] Daftar hanya dipakai jika perlu.

---

## 5. Format

- [ ] Judul jelas.
- [ ] Subjudul membantu navigasi.
- [ ] Tabel punya header.
- [ ] Kode memakai blok kode.
- [ ] Path dan perintah ditulis dengan benar.
- [ ] Tautan dapat dibuka.
- [ ] Tidak ada bullet Unicode.
- [ ] Tidak ada em dash.
- [ ] Tidak ada karakter non-ASCII.

---

## 6. ASCII

- [ ] Semua karakter berada di U+0000 sampai U+007F.
- [ ] Kutip lurus, bukan kutip melengkung.
- [ ] Tiga titik, bukan elipsis Unicode.
- [ ] Panah `->`, bukan panah Unicode.
- [ ] Hyphen atau koma, bukan em dash.
- [ ] `deg`, bukan simbol derajat.
- [ ] `+/-`, bukan simbol plus-minus.
- [ ] Spasi biasa, bukan non-breaking space.
- [ ] `check_ascii.py` lulus.

Perintah:

```bash
python3 .opencode/skills/senior-writing/scripts/check_ascii.py <file>
```

---

## 7. Bukti dan Kejujuran

- [ ] Sumber disebut.
- [ ] Asumsi disebut.
- [ ] Batasan disebut.
- [ ] Tidak ada klaim berlebihan.
- [ ] Tidak ada kutipan palsu.
- [ ] Tidak ada angka tanpa dasar.
- [ ] Tidak ada kesimpulan yang melompat.

---

## 8. Nada

- [ ] Langsung.
- [ ] Hormat.
- [ ] Tenang.
- [ ] Tidak defensif.
- [ ] Tidak menggurui.
- [ ] Tidak sloganis.
- [ ] Tidak menyalahkan individu.

---

## 9. Final

- [ ] Baca ulang dengan suara keras.
- [ ] Minta orang lain membaca ringkasan.
- [ ] Cek ejaan.
- [ ] Cek konsistensi istilah.
- [ ] Cek tanggal dan angka.
- [ ] Cek tautan.
- [ ] Cek ASCII.
- [ ] Kirim.

---

## 10. Severity untuk Review Tulisan

- **Blocker** - klaim menyesatkan, data salah, risiko tidak disebut.
- **High** - tujuan tidak jelas, rekomendasi tidak dapat ditindaklanjuti.
- **Medium** - struktur berantakan, paragraf terlalu panjang, jargon.
- **Low** - gaya, konsistensi, format.
- **Nit** - preferensi penulisan.

---

## 11. Pertanyaan Terakhir

1. Apakah pembaca bisa mengambil keputusan setelah membaca ini?
2. Apakah ada kalimat yang bisa dihapus tanpa kehilangan makna?
3. Apakah setiap angka bisa dipertanggungjawabkan?
4. Apakah setiap klaim punya dasar?
5. Apakah ada karakter non-ASCII?
6. Apakah ini sudah cukup pendek?
