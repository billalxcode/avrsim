## 4. Batas Klaim

- Skill ini merangkum prinsip, bukan menggantikan buku.
- Jangan mengklaim "menurut buku" tanpa merujuk halaman/kutipan yang valid.
- Jangan mengarang isi bab.
- Jika sumber ringkas, tandai "cakupan terbatas".
- Bab 29 ditulis James Grenning; bab 34 ditulis Simon Brown. Jangan mengatribusikan ke Robert C. Martin.
- Jangan menyalin isi buku ke kode/dokumen publik.
- Untuk detail lengkap, baca buku resmi.

## 5. Format Sitasi Internal

Jika merujuk cache:

```
Sumber: .caches/clean-architecture/by-chapter/ch22-the-clean-architecture.md
```

Jika merujuk buku:

```
Robert C. Martin, Clean Architecture, Ch. 22.
```

Jika merujuk blog:

```
Robert C. Martin, "The Clean Architecture", 2012.
```
